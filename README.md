# PhuwitShop — ตลาดซื้อขายไอดีเกม (PHP + MySQL)

ระบบทดลองซื้อขายไอดีเกม ใช้ PHP, MySQL (PDO) และ CSS

- **ผู้ขาย:** แอดมินเท่านั้น (ลงขายไอดีจากเมนู "จัดการร้าน")
- **เกม:** กำหนดเอง แอดมินเพิ่ม/แก้ไข/ซ่อนเกมได้เอง
- **การชำระเงิน:** จำลอง (demo) ไม่ตัดเงินจริง ไม่เชื่อมธนาคารหรือ Payment Gateway

## ความต้องการ
- XAMPP (Apache + MySQL), PHP 8.0+ (ต้องเปิด extension `openssl` ซึ่ง XAMPP เปิดไว้ให้แล้ว)

## ติดตั้งบน Windows ด้วย XAMPP
1. แตกโฟลเดอร์ `phuwitshop` ไปไว้ที่ `C:\xampp\htdocs\phuwitshop`
2. Start Apache และ MySQL ใน XAMPP
3. เปิด `config/database.php` แล้วตั้ง `APP_KEY` เป็นข้อความสุ่มยาวๆ (ตั้งก่อนเพิ่มไอดี และห้ามเปลี่ยนภายหลัง)
4. เปิด `http://localhost/phpmyadmin` > สร้างฐานข้อมูลชื่อ `phuwitshop` (collation `utf8mb4_unicode_ci`) > เลือกฐานข้อมูลนั้น > แท็บ Import > นำเข้า `database.sql`
   (**ไฟล์นี้ลบตารางของระบบเติมเกมเดิม** เช่น products, order_items แล้วสร้างใหม่ ส่วนตาราง users ยังอยู่)
5. เปิด `http://localhost/phuwitshop/setup_admin.php` เพื่อสร้างแอดมิน (`admin` / `Admin123!`) และไอดีตัวอย่าง
6. **ลบไฟล์ `setup_admin.php` ทันที** แล้วเปลี่ยนรหัสผ่านแอดมิน
7. เปิด `http://localhost/phuwitshop/`

ถ้าไม่ได้วางไว้ที่ `/phuwitshop/` ให้แก้ `BASE_URL` ใน `config/database.php`

## อัปเดตล่าสุด
- หมวดหมู่เกมหน้าแรกคลิกกรองได้ (`index.php?game=ID`) มีปุ่ม "ทั้งหมด"
- โลโก้ใหม่แบบ SVG (`assets/img/logo.svg`) ใช้ที่เมนู หน้าแรก และ favicon
- แอดมิน: `admin/reports.php` ดูยอดขายรายวัน/เดือน/ปี และกด "ดูผู้ซื้อ" เพื่อดูว่าใครซื้อ
- แอดมิน: `admin/members.php` ดูจำนวนสมาชิก ใครเคยซื้อ ยอดซื้อรวม และประวัติซื้อรายคน
- หน้ารายละเอียดสินค้ามีแกลเลอรีหลายรูป (ใส่ URL รูปเพิ่มเติมในหน้า "ไอดีเกมที่ขาย")
- **ถ้าใช้ฐานข้อมูลเดิมอยู่แล้ว** ให้รัน `migrate_add_images.sql` ใน phpMyAdmin 1 ครั้ง (ไม่ลบข้อมูลเดิม) ถ้าติดตั้งใหม่ด้วย `database.sql` ไม่ต้องรัน

## นำขึ้นเว็บโฮสต์ (InfinityFree)
1. สร้าง MySQL Database ในแผงควบคุม แล้วจดค่า Host / ชื่อฐานข้อมูล / ผู้ใช้ / รหัสผ่าน
2. แก้ `config/database.php` ใส่ค่าฐานข้อมูล และตั้ง `APP_KEY` เป็นข้อความสุ่มยาว ๆ (`BASE_URL` หาเองอัตโนมัติ)
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปไว้ใน `htdocs/` (ลบ `index2.html` ของโฮสต์ถ้ามี)
4. phpMyAdmin → เลือกฐานข้อมูล → Import `database.sql` (ไฟล์นี้ไม่ได้สร้างฐานข้อมูลให้ ต้องสร้างเองก่อน)
5. เปิด `/setup_admin.php` แล้วลบไฟล์นี้ทิ้งทันที จากนั้นล็อกอินและเปลี่ยนรหัสผ่านที่หน้า `change-password.php` (กดที่ชื่อผู้ใช้บนเมนู)
6. เลือก PHP 8.0+ และเปิด Free SSL
- ระบบตั้งเวลาเป็นเวลาไทย (UTC+7) ให้อัตโนมัติ รายงานยอดขายรายวันจึงไม่เหลื่อมวัน
- มี `.htaccess` กันไม่ให้เปิดไฟล์ `.sql` `.md` และโฟลเดอร์ `config/` `includes/` ตรง ๆ

## ขั้นตอนการทำงาน
1. แอดมินเพิ่มเกม (`admin/games.php`) และลงขายไอดี พร้อมข้อมูลล็อกอิน (`admin/accounts.php`)
2. ผู้ซื้อสมัครสมาชิก เลือกไอดี กด "ซื้อไอดีนี้" ระบบจะ **จองไอดี** ให้ 30 นาที (ปรับที่ `ORDER_TIMEOUT_MIN`)
3. กดยืนยันการชำระเงินจำลองที่ `payment.php` ไอดีจะเปลี่ยนเป็น "ขายแล้ว"
4. ผู้ซื้อดูข้อมูลล็อกอินได้ที่ `order.php` (เฉพาะเจ้าของคำสั่งซื้อที่ชำระแล้ว)
5. แอดมินกด "ปิดงาน" ที่ `admin/orders.php` เมื่อส่งมอบเรียบร้อย
- คำสั่งซื้อที่ไม่ชำระภายในเวลาที่กำหนด หรือถูกยกเลิก จะคืนไอดีให้พร้อมขายอัตโนมัติ

## โครงสร้างฐานข้อมูล
`users` · `games` · `accounts` (1 แถว = 1 ไอดี) · `account_credentials` (ล็อกอินเข้ารหัส AES-256-GCM) · `orders` · `payments`

## ข้อจำกัดและความปลอดภัย
- เป็นระบบ DEMO ห้ามใช้รับเงินจริง และอย่าใส่ข้อมูลล็อกอินของไอดีเกมจริงที่ไม่ใช่ของคุณ
- ก่อนใช้งานจริงต้องมี HTTPS, รหัสผ่านฐานข้อมูล, สำรองข้อมูล, Payment Gateway จริง และตรวจสอบความปลอดภัย
- การซื้อขายไอดีอาจขัดกับข้อตกลงของผู้พัฒนาเกมบางเกม ควรตรวจสอบเงื่อนไขของแต่ละเกมก่อนลงขาย
- ใช้เฉพาะภาพ/โลโก้ที่มีสิทธิ์นำมาใช้
